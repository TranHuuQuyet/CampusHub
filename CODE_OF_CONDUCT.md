# Contributor Covenant Code of Conduct

## Our pledge

We are committed to creating an open, welcoming, diverse, and safe environment for everyone in the CampusHub community.

## Our standards

The following behaviors help create a positive environment:

- Use respectful and friendly language
- Respect different opinions and experiences
- Accept constructive feedback
- Focus on solutions and community benefit
- Value and respect individual differences

The following behaviors are not accepted:

- Harassment, insults, or abusive language
- Threats or violent behavior
- Spam or inappropriate advertising
- Sharing another person's private information without consent

## Enforcement responsibilities

Project maintainers have the right and responsibility to remove, edit, or reject contributions that do not align with this Code of Conduct.

## Reporting

If you experience inappropriate behavior, please contact the project maintainers through the official communication channel listed in the repository.

## Scope

This Code of Conduct applies to all community spaces, including issues, pull requests, discussions, email, and project-related events.
