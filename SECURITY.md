# Security Policy

We take the security of CampusHub seriously and welcome reports of security vulnerabilities.

## Reporting a vulnerability

If you discover a security issue, please do not disclose it publicly in a public issue.

Instead, report it privately to the maintainers via the email or contact channel specified in the repository.

Please include details such as:

- Vulnerability description
- Potential impact
- Steps to reproduce
- Suggested remediation, if available

## Response timeline

We will make every effort to respond promptly and verify the issue as quickly as possible.

## Responsible disclosure

We encourage private reporting so we can address the issue before any public disclosure.

Thank you for helping protect CampusHub.
