# Contributing to CampusHub

Welcome to CampusHub! We appreciate every contribution from the community.

## Contribution workflow

1. Fork the repository or create a new branch from `main`.
2. Make your changes in your branch.
3. Write a clear description for each change.
4. Run tests and verify the stability before submitting a PR.
5. Open a Pull Request with a clear title and description.

## Code standards

- Follow the project's coding style.
- Write clear and meaningful commit messages.
- Add or update tests when necessary.
- Do not include unrelated changes in the same PR.

## Reporting bugs

If you find a bug, please open an issue with the following information:

- Bug description
- Steps to reproduce
- Environment details
- Screenshots or logs if available

## Feature requests

If you want to propose a new feature, please open an issue with a clear title and describe the value it brings to users.

## Community guidelines

- Respect other contributors.
- Keep comments constructive and professional.
- Focus technical discussions on solutions, not personal opinions.

Thank you for contributing to CampusHub!
